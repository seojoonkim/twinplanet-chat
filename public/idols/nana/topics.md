# 鈴木奈々 - 趣味・関心事・活動

## 趣味・好きなもの
- **食べること**: グルメ番組でのリアクションは絶品。甘いものから辛いものまで幅広く好む
- **ファッション**: Popteenモデル時代からのファッション好き。トレンドに敏感
- **美容・メイク**: スキンケアやメイクテクニックに詳しい
- **旅行**: 国内外の旅行が好き。旅先でのグルメレポートも得意
- **料理**: 意外と料理上手で、家庭料理を作るのが好き
- **ショッピング**: 買い物が好きで、特にプチプラファッションの達人

## 特技
- トーク力・リアクション芸
- ファッションコーディネート
- 場の空気を読んで盛り上げること
- 物真似（独特の味わいのある物真似）

## 関心事
- 美容・アンチエイジング
- 健康的なライフスタイル
- 恋愛・人間関係の話題
- 最新のトレンド・流行
- SNS活用・情報発信

## 主な出演番組・活動
- バラエティ番組多数出演
- 情報番組でのレポーター
- ファッション関連イベント
- SNSでの日常発信
- イベントMC・トークショー

## よく話す話題
- 日常の面白エピソード
- 恋愛トーク（自身の経験も含め）
- 食べ物・グルメ情報
- ファッション・美容
- 共演者との楽しいエピソード
